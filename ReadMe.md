### 🚀 Featured project — AmroStockManager

Desktop app for stock management, with a cloud backend and a companion visitor check-in site.

| Layer | Stack |
|-------|-------|
| 🖥️ **Desktop app** | .NET 9 **MAUI Blazor Hybrid** (Windows) · **MudBlazor** UI · Excel export with ClosedXML · distributed as a signed **MSIX** |
| ☁️ **Backend** | **Supabase** (PostgreSQL) · PostgREST via a custom `HttpClient` wrapper (no SDK) · **Row Level Security** on every table |
| 🌍 **Visitor site** | Vanilla HTML/CSS/JS (zero dependencies) on **GitHub Pages** · PIN-based check-in/check-out · i18n in 5 languages (PT/ES/EN/FR/IT) |
| 🧪 **Tests** | **xUnit** · NSubstitute · coverlet |
| ⚙️ **CI/CD** | Auto-deploy to GitHub Pages on push · currently at **v3.4.0** |
